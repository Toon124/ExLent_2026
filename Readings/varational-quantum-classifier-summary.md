# Variational Quantum Classifier (PennyLane Tutorial)

**Authors:** Maria Schuld
**Year:** 2019
**Link:** https://pennylane.ai/demos/tutorial_variational_classifier/#imports

## Summary
This PennyLane tutorial demonstrates the process of building and training a variational quantum classifier (VQC). VQCs are quantum circuits that learn from labeled data to classify new samples. It uses two examples which come from two of the first papers to propose VQCs as machine learning models; the first being that VQCs can be used to emulate the parity function with basis encoding. The second example utilizes amplitude encoding as well a using the variational circuit to identify the first two classes of the Iris flower data set. While each example uses a different encoding method, they both rely on the same core components; the variational layer, measurement, the cost function, and an optimizer. 
The layer is the foundation of the VQC. Each layer is a basic circuit design repeated over to build the full circuit. This loop performs a rotation on each of the qubits before entangling them to the neighboring qubit. The circuit takes the input quantum state and translates it into a form that can be measured. Each layer has its own set of weights, with a single trainable bias added to the output, and these parameters are adjusted during training by an optimizer. This allows the circuit to learn patterns in the data by reducing the error between the predicted output and the correct label throughout many iterations.
The cost function is a key step in the development process of the VQC. It uses a square loss, a loss function used to measure the difference between the model’s predicted label and the correct label. The VQC is then run on the data to calculate prediction’s cost and factor in that loss to improve performance. The tutorial also tracks the accuracy based on how many of the predictions matched their labels. The cost function is able to calculate the loss, so that the optimizer can tune the weights and bias to improve the predictions.
Finally, the optimizer is what actually tunes the weights and bias. It uses the loss from the cost function to adjust them little by little, lowering the error each time. The tutorial uses a NesterovMomentum optimizer to do this. This is what makes a VQC work like a neural network, since both use trainable parameters and an optimizer to learn from data.
